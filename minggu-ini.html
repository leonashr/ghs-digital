Masukkan kode

Hanya pengelola yang mengetahui kode dapat membuka ruang impor materi mingguan melalui antarmuka ini.

Pilih file HTML Ibadah Mingguan yang diunduh dari pengelola GHS. Sistem hanya membaca data materi dan tidak menjalankan kode dari file yang diimpor.

Impor ini hanya mengubah pratinjau browser Anda. Untuk pembaruan seluruh jemaat, unggah file YYYY-MM-DD.json ke folder materi-mingguan di GitHub. GitHub menjadi sumber utama dan akan dibaca otomatis oleh semua halaman.

Pratinjau lokal berhasil. Agar materi tampil di semua perangkat, unggah file JSON pekan yang sesuai ke GitHub. Tombol unduh HTML di bawah hanya membuat cadangan yang berdiri sendiri.
